# Переводной дурак

Консольная реализация карточной игры **«Переводной дурак»** — подкидного дурака с переводом
атаки на следующего по кругу игрока. Проект выполнен на Java 17 без внешних зависимостей
(в тестах используется только JUnit 5) и собирается через Maven.

* один игрок играет с клавиатуры, остальные — компьютерные соперники;
* от 2 до 5 игроков, открытый или закрытый козырь;
* полный набор событий партии: раздача, атаки, защита, взятие, перевод, добор карт;
* партия воспроизводится по зерну генератора случайных величин;
* 132 автотеста, включая стресс-проверку на сотнях партий.

---

## 1. Правила партии

### Карты и козырь

* Колода — 36 карт: от шестёрок до тузов, по девять карт каждой масти.
* Козырь выбирается по масти самой младшей карты в колоде.
* В режиме `open` козырь виден всем игрокам, в режиме `closed` карта-козырь скрыта,
  и переводить атаку козырной картой нельзя.

### Атака и защита

* Игрок, который ходит, выкладывает одну или несколько карт: первая карта может быть
  любой, остальные — только того же достоинства, что уже лежит на столе (подкидные).
* Количество карт, выложенных за один отрезок, ограничено числом карт защищающегося
  на начало отрезка: нельзя завалить соперника «в одну очередь».
* Защищающийся отбивается одной картой: старше по достоинству либо козырная
  (козырь бьёт любую некозырную карту, но не бьёт другую козырную).
* Если отбиться нечем, защищающийся **забирает все карты со стола** (включая свои
  неотбитые карты) и становится атакующим. Неотбитые карты атакующего при этом
  остаются у него.

### Перевод атаки

* Сразу после полностью отбитой атаки защищающийся может **перевести** её на
  следующего по кругу игрока: тот обязан отбить новую атаку.
* Переводить можно картой того же достоинства, что и отбитая карта, а в режиме
  `open` — любой козырной картой.
* Число переводимых карт не может превышать число карт следующего игрока.
* Перевод возможен только в партии на троих и более игроков: вдвоём следующим по
  кругу был бы сам защищающийся.

### Добор карт и завершение партии

* После каждого раунда игроки, у которых осталось меньше шести карт, добирают
  недостающие из колоды по кругу, начиная со следующего атакующего.
* Партия заканчивается, когда у игрока не остаётся карт (он победил, остальные
  проиграли), либо когда **три раунда подряд не было продвижения**.
  Прогресс — это когда в отбой ушла хотя бы одна карта или кто-то добрал карты
  из колоды. Если карты лишь переходят из руки в руку, партия дальше двигаться
  не может: побеждают игроки с наименьшим числом карт, остальные считаются
  проигравшими (сортировка по убыванию числа карт).

## 3. Сборка и запуск

```bash
mvn clean package            # сборка и прогон тестов
java -jar target/durak-1.0.0.jar
```

Только сборка без тестов:

```bash
mvn -DskipTests package
```

### Параметры командной строки

| Параметр | Значение | По умолчанию | Описание |
|-----------|----------|---------------|----------|
| `--players=N` | 2…5 | 3 | количество игроков за столом |
| `--human=N` | 0 или 1 | 1 | количество игроков-людей |
| `--trump=open\|closed` | open / closed | open | режим козыря |
| `--seed=N` | любое целое | время запуска | зерно генератора случайных величин |
| `--names=A,B` | список через запятую | «Вы», «Компьютер N» | имена игроков |

Примеры:

```bash
java -jar target/durak-1.0.0.jar --players=4 --human=1 --trump=closed --seed=2024
java -jar target/durak-1.0.0.jar --players=3 --human=0 --names=Аня,Борис,Вера
java -jar target/durak-1.0.0.jar --help
```

### Управление в консоли

| Команда | Действие |
|---------|----------|
| `1 2 3` | сыграть карты с указанными номерами из показанной руки |
| `конец` | закончить атаку (защитник в этот момент ходит первым) |
| `взять` | забрать карты со стола вместо защиты |
| `перевести` | перевести отбитую атаку на следующего игрока |
| `нет` | отказаться от перевода |

Карты, которые нельзя сыграть сейчас, помечаются знаком `*`. Вывод печатается
в UTF-8, кодировка ввода определяется автоматически (UTF-8 либо кодировка
операционной системы).

## 4. Структура проекта

```
src/main/java/com/ctrlzz14/durak/
├── Main.java              точка входа, разбор параметров, сборка партии
├── model/                 карты, колода, руки, стол, игроки, состояние, правила
│   ├── Card, Deck, DiscardPile, Hand, Table
│   ├── Rank, Suit, TrumpMode, GamePhase, EndReason
│   └── Player, GameState, GameRules, GameResult
├── move/                  ходы игрока: атака, защита, взятие, перевод, конец атаки
├── rules/                 правила карт и проверка корректности ходов
│   ├── CardRules, MoveValidator, IllegalMoveException
├── engine/                GameEngine — цикл партии, фазы, события, добор карт
├── event/                 события партии и журнал событий
├── strategy/              PlayerStrategy — общий интерфейс стратегий
├── bot/                   SimpleBotStrategy — компьютерный соперник
└── cli/                   консольный слой: параметры, ввод-вывод, форматирование
```

Архитектурные принципы:

* **model** не знает ни о консоли, ни о случайных числах — это чистые данные;
* **rules** проверяет любой ход и не меняет состояние;
* **engine** единственный владелец состояния: он меняет фазы, ведёт журнал
  событий и объявляет результат партии;
* **strategy** описывает, *кто* играет (человек или бот), **cli** — только вывод;
* случайные величины приходят только из `random/GameRandom`, поэтому партия
  полностью воспроизводится по зерну.

## 5. Тесты

```bash
mvn test
```

132 теста покрывают:

| Класс | Что проверяется |
|--------|-----------------|
| `model/CardTest`, `model/DeckTest`, `model/HandAndTableTest` | карты, колода, рука и стол |
| `rules/CardRulesTest`, `rules/MoveValidatorTest` | сравнение карт и проверка ходов |
| `random/GameRandomTest` | детерминированность генератора |
| `engine/GameEngineTest` | ход партии: атака, защита, взятие, добор, результат |
| `engine/TransferRulesTest` | правила перевода атаки |
| `engine/StalemateTest` | правило тупика |
| `engine/GameFlowTest` | партии целиком на разных зёрнах |
| `engine/StressTest` | 2–5 игроков × 100 зёрен × 2 стратегии: партия всегда завершается |
| `cli/GameOptionsTest`, `cli/ConsoleInputTest` | разбор параметров и чтение ввода |
| `cli/EventFormatterTest`, `cli/ConsoleGameTest` | вывод событий и игровой цикл |
| `bot/SimpleBotStrategyTest` | поведение компьютерного соперника |

## 6. Воспроизводимость

Зерно генератора выводится в начале партии и принимается параметром `--seed`.
Одно и то же зерно при одних и тех же параметрах даёт полностью одинаковую
партию: расклад, козырь и все решения бота.

```bash
java -jar target/durak-1.0.0.jar --players=3 --seed=42
```
